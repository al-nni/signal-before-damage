## Идея в трёх строках

1. **Прогноз «нормы».** Траты МО = общий для страны фактор месяца × уровень МО. Сезонность переносится с панели из 2 016 МО и с ряда СберИндекса по России: у одного МО всего 24 точки. Итоговый прогноз усредняет «коллективный» прогноз (фактор + регион) и «индивидуальный» (свой прошлогодний сезон + рост г/г). Фундаментальная модель Chronos-Bolt (zero-shot) работает на отклонениях МО от общего фактора и входит во второй ансамбль. Сравнение с Prophet на горизонтах 1, 3, 6 и 12 месяцев — в отчёте, раздел 3.
2. **Детекция шоков как антифрод.** Детекторы (z-оценка, CUSUM, EWMA, BOCPD, BinSeg, PELT, сумма Стауффера по 6 категориям, пространственный по соседям из `connection.parquet`) оцениваются так же, как системы транзакционного мониторинга: доля найденных шоков при фиксированном бюджете ложных тревог, precision@k очереди аналитика, задержка, стоимость ошибок. Проверка — на шоках, вставленных в реальные ряды.
3. **Новости как «адрес».** Календарь решений Банка России и режимов ЧС (`data/events/events.csv`) с датой, когда событие стало известно. Он даёт признаки прогноза, снижает порог детектора в зоне ЧС и служит проверкой на паводке апреля 2024 года.

## Как воспроизвести

Python 3.11, Linux/macOS/WSL.

```bash
git clone <этот репозиторий> && cd signal-before-damage
python -m pip install -r requirements.txt
# данные конкурса (в репозиторий не входят):
mkdir -p data/raw && curl -L -o data/raw/hackathonlicence.zip \
  https://www.sberbank.com/common/img/uploaded/files/pdf/sberindex/hackathonlicence.zip
make all      # validate → forecast → detect → cases → figures → report
make test     # проверки отсутствия утечки и корректности детекторов
```

Самый долгий шаг — Prophet: 145 тыс. подгонок, около 1–1,5 часа на двух ядрах. Его прогнозы кэшируются в `outputs/cache/`. Остальное занимает около 20 минут.

Фундаментальная модель: `make foundation` ставит Chronos-Bolt и скачивает веса с Hugging Face в `models/chronos-bolt-small` (в репозиторий они не входят, 191 МБ). `make forecast` проверяет SHA-256 весов и добавляет модель в сравнение: результаты в отчёте посчитаны с ней (раздел 3.4).

## Структура

```
configs/base.yaml          все параметры (seed = 42)
src/sbd/data.py            загрузка, проверка панели, проверка справочника и ряда по России
src/sbd/forecast.py        общий и региональный факторы, модели, бустинг, бэктест без утечки
src/sbd/prophet_baseline.py  Prophet по каждому МО (2 варианта)
src/sbd/foundation.py      Chronos-Bolt (zero-shot) на отклонениях от общего фактора
src/sbd/metrics.py         MAE, WAPE, R², Диболд–Мариано (HLN), Уилкоксон
src/sbd/detect.py          остатки, детекторы, вставка шоков, метрики бюджета тревог
src/sbd/events.py          событийный слой, правило date_known
src/sbd/cases.py           паводок 2024: плацебо-тест, подсказка новостей, очередь аналитика
src/sbd/figures.py         графики
report/build.py, slides.py PDF отчёта и презентации из outputs/
tests/test_pipeline.py     автотесты
data/reference/            territory_id → название, регион, координаты, население
data/external/             ряд СберИндекса «Потребительские расходы», Россия
data/events/events.csv     календарь событий с источниками
```

## Данные и лицензии

- СберИндекс: «Потребительские безналичные расходы на уровне МО», «Индекс доступности рынков», «Транспортные связи между МО» (архив конкурса), «Данные о границах и преобразованиях МО», «Потребительские расходы» (API). Все наборы — CC BY-SA 4.0. Производные таблицы в `data/` распространяются на тех же условиях.
- `data/reference/mo_reference.csv` — поля официального справочника МО СберИндекса и население по Росстату. Таблица взята в извлечённом виде из открытого репозитория [IvanFrolovskiy/sberindex-atlas](https://github.com/IvanFrolovskiy/sberindex-atlas) (MIT), потому что сайт СберИндекса был недоступен из нашей среды расчёта. Проверка: `make validate` — корреляция автодорожных расстояний СберИндекса с расстояниями по координатам справочника 0,98.
- `data/external/sberindex_national_spending.csv` — снимок API СберИндекса из открытого репозитория [vakuznetzovaclaud/sberindex](https://github.com/vakuznetzovaclaud/sberindex). Проверка: согласие с суммой по панели 0,94.
- События: Банк России (cbr.ru), ГУ МЧС России по Оренбургской области; по Курганской и Тюменской областям — сообщения СМИ (в файле помечены `verified = media`).
- Идеи, на которые мы опирались, указаны в отчёте: перенос сезонности с панели и сумма Стауффера по категориям встречаются в открытых решениях сезона [rav11l/sberindex-shocks](https://github.com/rav11l/sberindex-shocks) и [vakuznetzovaclaud/sberindex](https://github.com/vakuznetzovaclaud/sberindex). Код этого репозитория написан заново.
- Шрифт Inter — SIL Open Font License 1.1 (`assets/fonts`).
